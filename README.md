# Vipin Singh · Portfolio

**Live:** https://meet-vipinsingh.vercel.app

Personal portfolio of Vipin Singh, Senior SDE – QA. Covers test automation across web, mobile and APIs, and agentic AI-driven QA workflows.

Built with React, TypeScript and Vite. No backend.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
```

## Edit content

All text (experience, projects, skills, contact details) lives in [`src/data.ts`](src/data.ts). Layout is in `src/App.tsx`, styles in `src/index.css` and `src/App.css`.

## Build

```bash
npm run build    # outputs to dist/
npm run preview  # serve the production build
```

Deployed on Vercel: every push to `main` goes live automatically.
